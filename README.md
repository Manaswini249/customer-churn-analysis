# Customer Churn Analysis

## Objective

Analyze customer behavior and identify patterns behind subscription cancellations.

## Features

- Customer churn calculation
- Churn rate analysis
- Login frequency analysis
- Support contact analysis
- Customer retention recommendations

## Technologies

- Python
- Pandas
- GitHub

## Dataset Features

- CustomerID
- Tenure
- LoginFrequency
- SupportContacts
- Subscription
- Churn

## Run

```bash
pip install -r requirements.txt
python churn_analysis.py
```

## Output

- Churn statistics
- Churn rate
- Customer behavior insights
- Retention recommendations
